# Canada Rates Strategy Lab

An ongoing quantitative research project focused on Canadian government bond yields, yield-curve dynamics, relative-value analytics, and systematic interest-rate strategy research.

## Planned Features

- Canadian government bond yield monitoring
- 2-year, 5-year, and 10-year yield-curve analysis
- Term-spread and basis-point movement analysis
- Historical yield-curve visualization
- Statistical relative-value signals
- Historical strategy backtesting
- Automated rates strategy research summaries

## Planned Stack

Python, pandas, NumPy, Streamlit, Plotly, Bank of Canada API.

## Status

Under active development. Initial repository created October 2026. Implementation and documentation will be added incrementally.

## Data Source

Bank of Canada Valet API.
